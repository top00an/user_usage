# 정직한 불확실성 — 이 레포의 관통 규율

> **근사를 정확한 값으로 위장하지 않는다.** 이걸 지우면 화면이 더 깔끔해지는데, 그게 이
> 도구가 하지 않기로 한 일이다. (`go/CONTRACT.md`)

이 레포의 거의 모든 설계 결정이 이 한 문장에서 나온다. 개별 사례를 흩어 두면 "왜 이렇게
번거롭게 했지"로 읽히므로 여기 모은다.

## 규칙 셋

1. **모르는 것은 모른다고 표시한다** — 0 이나 그럴듯한 추정으로 채우지 않는다.
2. **조용한 오분류보다 시끄러운 미지가 낫다** — 허용목록 밖 값을 기본값으로 접지 않는다.
3. **판정은 언제나 버리는 쪽으로 기운다** — 다만 *버렸다는 사실*은 남긴다.

## 사례 — 화면에서

| 자리 | 무엇을 밝히나 |
|---|---|
| 모델별 표 `근거` 열 | 정확값(`fromSeries`) vs 근사(`fromSession`) → [[model-three-paths]] |
| 사용자별 series 커버리지 | 그 사람 데이터 중 정확값의 비율 |
| `unpriced` 목록 | 공식 단가가 없는 모델 이름 — 합계가 **과소**임을 밝힌다 → [[cost-model]] |
| `ttlUnknownRows` | TTL 미상 N행 · 최대 1.6배 과소 |
| 키워드 보존 기한 | 추세가 끊기는 이유를 보는 사람이 알아야 한다 → [[data-policy]] |
| 수집 커버리지 | 어느 발신처가 보고를 멈췄나 |
| **플랫폼 지원 배지** | `미수집`(그 도구가 기록 안 함)과 `해당 없음`(개념 자체가 없음)을 **가른다** → [[platform-coverage]] |

> ⚠ **2026-08-12 변경 — 이 규율이 한 화면에서 약해졌다.** 대시보드 탭의 플랫폼 섹션에서
> 지표×플랫폼 지원표를 제거했다. 그 섹션이 세우는 축(세션·토큰 네 축·비용)은 네 플랫폼 모두
> 수집되므로 **`미수집` 배지가 붙을 자리가 남지 않았고**, 그 표기는 이제 두 곳에서만 보인다:
> **아키텍처 탭**의 수집 범위 표와 **사용 추적 탭**의 축 패널. `해당 없음`(캐시생성)은 카드와
> 비교표에 그대로 남는다. 판정 자체는 `lib/platforms.ts` 의 `supportOf()` 하나가 계속 소유한다.

## 사례 — 서버에서

| 결정 | 대안(하지 않은 것) |
|---|---|
| 모르는 모델은 `priced=false` + 이름을 `unpriced` 에 남긴다 | 조용히 $0 처리 → 합계가 틀렸다는 사실이 화면에서 사라진다 |
| 허용목록 밖 `platform` 은 `other` 로 남긴다 | `claude` 로 접기 → 다른 도구 사용량이 claude 로 계산되는 **조용한 오분류** |
| `?platform=` 오타는 **400** | `other` 로 접기 → 요청한 것과 다른 모집단이 요청한 이름으로 돌아온다 |
| `USAGE_DB_MODE` 오타는 **부팅 거부** | local 로 조용히 접기 |
| RLS 판정 불가(터널 미개통)는 **거부하지 않되 stderr 로 크게 남긴다** | 조용히 통과 → 검사가 안 돌았다는 사실 자체가 기록돼야 한다 |
| 계단(롱컨텍스트) 요금은 **"계단 없음"과 "계단 여부를 모름"을 구분**한다 | 둘 다 표준가 → 후자가 과소일 수 있다는 사실이 사라진다 |
| `stats.SummarizeAny` 가 `dropped`(관측이 아닌 값의 개수)를 센다 | `[]float64` 변환 → `null` 이 "0 이라는 관측"으로 둔갑 |
| 구버전 수집기의 `series` 없는 보고를 **받는다** | 거절 → 그 사람의 사용량이 통째로 사라진다 |
| 자리표시자 모델은 `(미상)` 으로 접는다 | 실제 모델명처럼 방치 → [[cleanup]] |
| 압축된 Codex 롤아웃을 **건너뛴다고 찍는다** | 침묵 → 사용량이 빠진 줄 모른다 |

## 사례 — 비용 라벨

화면의 비용은 어디서나 **"API 환산 비용"** 이고, **그것이 청구액이 아니라는 사실을 함께
말한다.** 구독 요금제(ChatGPT Plus·Claude·Antigravity)는 토큰당 과금이 없으므로 이 숫자는
"같은 토큰을 API 종량제로 썼다면 얼마였을까"다.

라벨의 단일 출처는 `web/lib/costLabels.ts` — 한 곳에서만 쓰면 문구가 갈리지 않는다.

> 쓸모는 그대로다 — 사용자·모델·플랫폼 간 **비교**에는 그대로 쓰인다. 다만 이 값을 경리에
> 청구서로 넘기면 안 된다. (`README.md`)
