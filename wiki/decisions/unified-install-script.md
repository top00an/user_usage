# 결정 — 설치와 제거를 한 스크립트에 둔다

## 원안 vs 실제

| | 계획(S5) | 구현 |
|---|---|---|
| 산출물 | "훅 스크립트 + 붙여넣을 설치 스니펫" 둘 | **원커맨드 설치기 하나** |
| 범위 | Claude `SessionEnd` | + Antigravity `statusLine`·`Stop` + 파일 원천 셋 |
| 제거 | (없음) | **같은 스크립트의 `--uninstall`** |

계획서가 스스로 "**계획을 넘어섬**"이라 기록했다.

## 왜 설치와 제거가 한 파일인가

> 제거는 설치가 **무엇을 어떤 키로 넣었는지** 알아야 하는데, 그 지식이 두 파일로 갈리면
> **한쪽만 고쳐진 채 어긋난다.** (`docs/OPERATIONS.md` §4)

그래서 `--uninstall` 은 `--key`·`--server` 를 받지 않는다 — 제거에 필요한 값(설치 경로·
보관해 둔 원래 상태줄)이 `config.env` 에 이미 있다.

## 왜 훅 스니펫을 붙여 넣게 하지 않는가

세 가지를 사람이 손으로 하면 반드시 틀린다:

1. **JSON 병합** — 기존 훅·`theme`·`statusLine` 을 보존하면서 우리 것만 넣기
2. **멱등** — 재실행해도 중복되지 않게(우리 것만 제거 후 재삽입)
3. **토큰 격리** — 평문이 `settings.json` 에 들어가지 않게

특히 3번. `settings.json`·`hooks.json` 은 **공유·백업·스크린샷으로 새어나가기 쉬운** 파일이다.
스크립트는 토큰을 `config.env`(600)에만 두고 훅이 그것을 sourcing 하게 한다.

## 왜 수집기 다운로드에 키를 요구하는가

`GET /api/agent/collector` 는 인제스트 키가 필요하다. 무인증으로 두면 서버가 임의의 사람에게
실행 파일을 배포하는 자리가 된다.

반면 `/install.sh` 자체는 **무인증**이다 — 그 스크립트는 키 없이 아무것도 하지 못하므로
**키가 인증을 대신한다.**

## 왜 https 를 강제하는가

이 스크립트는 서버에서 받은 바이너리를 `chmod +x` 후 **실행한다.** 평문 http 는 중간자가
임의 코드를 심을 수 있는 자리다. 예외는 loopback(`127.0.0.1`·`localhost`)뿐이고, 그건 로컬
테스트용이다.

## 왜 JSON 도구가 없으면 멈추는가

`jq → python3 → node` 셋 다 없는데 설정 파일이 이미 존재하면 **덮지 않고 멈춘다.** 손상
JSON 이어도 한 바이트도 안 건드린다.

> **남의 설정을 깨뜨리느니 설치를 포기하는 쪽이다.**

제거는 여기서 한 걸음 더 간다 — 도구 유무·JSON 유효성을 **선행 점검에서 전부 보고 나서야**
지우기 시작한다. 바이너리를 먼저 지운 뒤 JSON 에서 실패하면 "훅은 남았는데 수집기는 없는"
반쪽 상태가 되고, **그 상태는 매 세션 조용히 실패한다.**

## 왜 없는 도구를 조용히 스킵하는가

Antigravity CLI 가 없으면 그 단계가 **통째로 조용히 빠진다.**

> 안 쓰는 사람의 설치 로그를 **남의 도구 목록**으로 만들지 않기 위해서.

같은 규율이 [[collector]] 에도 있다 — 원천 디렉터리가 없으면 조용히 건너뛴다.

## 왜 statusLine 을 덮지 않고 체이닝하는가

statusLine 자리는 **하나뿐**이다. 덮으면 그 사람이 쓰던 상태줄이 사라진다. 대신 원래 명령을
`AGY_PREV_STATUSLINE` 으로 보관하고 **출력을 그대로 통과**시킨다 — 화면은 그들 것이다
→ [[antigravity]].

## 왜 제거가 서버의 키를 해지하지 않는가

**운영자 자격이 필요한 서버 쪽 작업**이라 개발자 PC 의 스크립트가 대신할 수 없다. 대신 제거
출력의 마지막 두 줄이 그 방법을 안내한다.

⚠ **퇴사·이탈이면 반드시 해지까지** — 제거는 그 PC 에서 보고를 멈출 뿐, 유출된 키는 다른
곳에서 그대로 쓴다 → [[ingest-keys]].

## 검증 방식 — grep 이 아니라 실제 왕복

`go/internal/httpapi/agent_test.go` 는 **임시 HOME 에 실제로 설치하고 실제로 제거한다**
(수집기는 가짜 셸 스크립트로 내려받는다). 문자열 검사가 아니다.

그리고 **원본을 돌린다** — 임베드 사본이 원본과 같은지는 별도 테스트가 본다
→ [[installer]] · [[webroot-embed]].
